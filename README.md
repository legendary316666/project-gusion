# Project Gusion

**Project Gusion** is a seller operations and catalog SEO optimization tool built for authorized shop owners.

## What It Does
- **OAuth 2.0 Shop Connection:** Connects only to shops where the shop owner explicitly grants authorization via OAuth 2.0 (PKCE).
- **Catalog & SEO Auditing:** Reads listing metadata (titles, tags, descriptions, pricing, and inventory) to check SEO completeness and formatting.
- **Seller-Approved Updates:** Prepares and pushes listing updates only after explicit review and approval by the shop owner.

## Data & Privacy
- Access is limited strictly to the authorizing shop owner and our internal operations team.
- No buyer PII or external marketing/email lists are harvested or exported.
- OAuth tokens are stored securely and revoked immediately upon shop offboarding or request.
